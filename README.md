# Прогнозирование движения крипторынка

Проект посвящён задаче [DRW Crypto Market Prediction](https://www.kaggle.com/competitions/drw-crypto-market-prediction/overview) на Kaggle: по рыночным данным нужно предсказывать дальнейшее движение криптовалютного рынка.

Я работал над проектом не в одиночку, а вместе с преподавателем в кружке Яндекса. В ходе работы я разобрался в подходах к прогнозированию движения рынка и применил их в ноутбуке [`catboost-crypto-seminar.ipynb`](catboost-crypto-seminar.ipynb).
